# 🚗 Caroo

![Caroo Banner](https://images.unsplash.com/photo-1492144534655-ae79c964c9d7?q=80&w=1400&auto=format&fit=crop)

## About The Project

Caroo is a modern car marketplace website built using full-stack development.
Users can browse cars, search by brand, create accounts, and add their own cars for sale.

The project is designed with a clean and responsive UI for both desktop and mobile users.
